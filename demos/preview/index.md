流程 HTML（`demos/round-0XX-*.html`）与 UX HTML 分开：前者是步骤节点与状态机，只说明逻辑；后者是用户实际看到的界面。动 UI 的轮次主交付必须是 UX HTML + PNG 预览。

纸质样板只取质感（色板、纹理、衬线、圆角、窗口 chrome），位置重新组织：不采用三栏拖拽与右栏公告。KCU 品牌内联 SVG，无外部字体与远端脚本，无源稿品牌字面量。

手感回路：先看图 → 提意见 → 先改演示与截图 → 确认后才改实现。本目录是演示产物，未进入 `src/`。017 轮 `ui-full-kcu-v2.html` 风格取错，保留文件但已作废。
