极简窗口

KCU 轻量启动器 · 单主题 · 无重资产
游戏运行期启动器退出，后台无常驻进程；不加载本页任何组件与资产。

与正常模式的边界

排除 13 项：三栏拖拽、双主题实现、纹理、日志抽屉、衣柜、工具箱…
保留：三种登录、三级回退、批量下载、基础日志、系统文件面板
低端机优先：不加载 WebView2 重资产，除非登录需要
异常与边界状态空态 / 加载态 / 错误态 / 被锁态 / 安全模式error

空态

还没有实例。新建一个，或从服务器列表双击直接进服。

加载态

正在准备实例，可取消，取消后 0 副作用。

错误态

外置 / 内置 / 连接码全部失败。零级报错：明确修复建议，不崩溃、不静默。

被锁态

实例目录被占用，界面已锁定；OS 级防护 + lockfile。

安全模式

连续失败 3 次进入：忽略自定义配置、禁 UI 与正版，导出 4 行诊断包。

离线态

无网络：已缓存列表可见，下载入口提示离线，不反复发请求。
