## 决策

| 编号 | 项 | 值 | 依据 |
| --- | --- | --- | --- |
| D01 | 探测异步化 | worker-pull 有界队列，UI 先渲染上次结果再增量更新；单台有 deadline；取消后不再写新结果、不再发新请求 | 022 指令 / R01 / R02 / C01 / C08 |
| D02 | 设备连接范围 | 两个上限：本次可连总台数 + 同时连接路数；按权重取前 N 台进入计划，范围外不发请求、保留上次结果 | 022 指令 / C01 / C04 / C05 |
| D03 | 档位表 | 标准 `limit=4 / concurrency=3`；轻量 `limit=2 / concurrency=2`；无界面 `limit=0 / concurrency=0`；数值可在设置里改 | D02 / 007 D04 / 016 轻量约束 |
| D04 | 新加服务器 | 强制排到队首、不受 N 裁剪，一定连一次；但占同一份额度，不额外扩总量（挤掉权重最低的一台） | 022 指令「新的不会受影响但是要保持在设备连接的范围内」 |
| D05 | 范围外 | 保留上次结果、按缓存权重排序、不发请求；不隐藏、不删除 | 022 指令 / C01 缓存降级 |
| D06 | 失败历史分类 | `ever=true`（有成功案例）：继续参与探测，本轮失败沉底；`ever=false && tried=true`（测过且无成功案例）：不主动探测、按缓存权重排中段、不沉底 | 022 指令 / R02 / R03 |
| D07 | 排序档位 | 锁定 0 → 可用 100+ → 范围外 200+ → 无成功记录 300+ → 曾成功但本轮失败 900+；档内按缓存权重 | D05 / D06 / 021 D05 |
| D08 | 锁定不受影响 | 锁定项始终置顶，连不上、超范围、无成功记录都不改变其位置 | 021 D05 / 022 指令 |
| D09 | 界面 | 服务器页加「连接范围」卡（本次可连 / 同时连接 / 在飞·队列 / 本次不连 / 进度条 / 切档 / 停止）；设置 → 服务器与连接 加「设备连接范围」分组，含自定义台数、并行数、轻量档、新服与范围外口径 | 020 D09 / 021 D01 |
| D10 | 产品文案 | 界面不写并发池、背压、context、档位枚举等工程词；工程结论只落 docs/ | 021 D01 |
| D11 | 范围 | 只交付 UX HTML、37 张产品视图 PNG、设计 / 调研 / 决策 / 功能 md、索引与规则；`src/` 与 Cargo.lock 无变化 | 003 D07 |

## 与 021 的差异

| 项 | 021 | 022 |
| --- | --- | --- |
| 探测 | `srvSync` 同步遍历全部服务器改 ping | `srvProbe` 异步 worker-pull，按计划只连 N 台 |
| 总台数 | 全量 | 卡在设备档位内 |
| 并发 | 无 | 标准 3 路 / 轻量 2 路 |
| 失败历史 | 只有 `ok` 布尔 | `ever` / `tried` / `isNew` / `offlineMark` 四类 |
| 无成功记录 | 与连不上一起沉底 | 不主动连、按缓存权重排中段 |
| 范围外 | 无此概念 | 不连、保留上次结果、按权重排 |
| 新加服务器 | 直接 push 且算在线 | 强制入队但占同一份额度 |
| 取消 | 无 | 停止按钮，取消后 0 新请求 |
| 观测 | 上次同步时间 | 可连 / 并发 / 在飞·队列 / 不连 / 进度条 |
