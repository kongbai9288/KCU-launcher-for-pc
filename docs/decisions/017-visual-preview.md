## 决策

| 编号 | 项 | 值 | 依据 |
| --- | --- | --- | --- |
| D01 | 提交形态 | 动 UI 的轮次除整页 HTML 外，必须交 PNG 预览与一张总览拼图；用户能在对话里直接看到界面长相 | 本轮指令「看不到用户界面是什么样的」 |
| D02 | 渲染方式 | `scripts/render_ui.py` 调本地 chromium 按 `#scene=` 逐场景截图 1440×900，PIL 拼 `00-overview.png`；全程离线、无远端字体与脚本 | 本轮实测 chromium 156 可渲染 |
| D03 | 风格边界 | 样板稿只取视觉风格：青绿 KCU 主色、深色底、圆角、细腻描边、卡片层次、轻噪点；**不取**组件位置、三栏拖拽、1440×900 窗口结构、左右分栏层级 | 本轮指令「只是要那个风格不代表位置都要按照那个位置放」 |
| D04 | 布局重排 | 顶部品牌条（logo / 搜索 / 铃铛 / 主题 / 模式）+ 精简左导航 + 卡片流主区 + 底部状态条；公告放独立页与弹窗，不塞进原稿右栏 | D03 |
| D05 | 品牌与授权 | KCU 内联 SVG；不复制样板代码、FCL 品牌、外部字体 CDN；`assets/ui/normal-mode-v3.html` 仍停在资产层 | 007 D08 / 014 D03 |
| D06 | 主动补齐 | 用户未点名但会出现的界面一并出图：公告中心、公告详情、更新提示、首次启动引导、维护/活动公告、弹窗全集、异常状态、设置、关于、日志、下载进度、实例与服务器、登录、轻量视图 | 本轮指令「得多思考」「公告什么的也得让我看看」 |
| D07 | 公告族规则 | 四类标签（置顶 / 版本更新 / 活动 / 维护）+ 未读高亮 + 已读降噪；不自动弹窗打断操作；维护公告只在相关入口提示；每条有「不再提示」与关闭路径，流程结束 0 残留 | 015 D03 / core.popup 目录 |
| D08 | 手感回路 | PNG 总览 → 用户按图提意见 → 先改演示与截图 → 确认后才改实现；本轮 `src/` 不变 | 015 D04 / 016 D04 |
| D09 | 模式边界 | 正常模式取样板风格并重排位置；轻量模式独立极简视图，不复用本页任何组件；无头模式不加载界面 | 007 D03-D06 / 016 D08 |
| D10 | 本轮范围 | 只交付可视化与文档；不写业务代码、不进构建、不生成 LICENSE | 003 D07 阶段判定 |
