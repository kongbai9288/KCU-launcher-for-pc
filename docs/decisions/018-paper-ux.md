## 本轮真实缺陷与修复

| 编号 | 现象 | 处置 |
| --- | --- | --- |
| E01 | 首次渲染 19 张全部继承深色主题 | `page.goto` 仅改 hash 不重载，浏览器保留上一场景 theme；改为每场景带 `?r=<i>` 强制重载，重渲染后仅 S02 为深色 |
| E02 | 折痕与噪点过重，浅色纸面出现明显 X 形黑线 | 折痕透明度下调（浅色 .045→.022 等，深色 .28→.10 等），噪点 alpha 16→9 / 14→8 |
| E03 | 深色纸质主题正文继承 body 深墨色，标题与统计数值不可读 | `.win[data-theme="dark"]` 补 `color:var(--ink)`；primary 按钮文字改 `#26272A`；搜索框补 `color` |
| E04 | 窗口 900px + 底部说明文字撑高 flex，标题栏与状态栏被裁 | 说明文字改 `position:fixed` 且透明，窗口完整可见 |
| E05 | 20px 方形 logo 挤三字母 | 改单字 `K` |
