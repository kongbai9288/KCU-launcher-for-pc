### C04 插件哈希口径

| 项 | 值 |
| --- | --- |
| 我定的默认 | 身份哈希 `sha512(plugin_id)[..16]`，落在 `src/plugins/identity.rs`；`decide_upgrade` 用它判定「哈希一致且版本更高 → 需手动同意」 |
| 原文 | `docs/spec/37-round-037-instructions.txt`：「如果两个插件的哈系值满足一致，那么在对比版本号用户得手动同意才能安装（这叫升级）」 |
| 身份哈希后果 | 同一插件 ID 的不同版本哈希相同 → 版本比较可达 → 升级确认可达 |

| 处置 | 不改口径；补上述两种后果；**Q-037-01 仍待拍板**。054 结尾曾把它列为「还挂着的」，本轮确认状态一致 |
