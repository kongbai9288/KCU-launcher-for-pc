# 证明规则

| 值 | 定义 |
| --- | --- |
| 已证实 | 有可复现外部证据：命令输出、文件内容、接口返回 |
| 已失败 | 明确失败，附报错与返回码 |
| 未证实 | 证据二手、过期、或窄于声明 |
| 受阻 | 具名检查跑不动，给出原因 |

## 约束

| 编号 | 规则 |
| --- | --- |
| P01 | 每条结论落到四值之一，禁止中间态 |
| P02 | 不依赖模型自省，必须外置验证 |
| P03 | 每轮回复前执行 `TZ='CST-8' date '+%a %b %e %H:%M:%S %Z %Y'` 并回显 |
| P04 | 时间戳不构成的后续动作证据，证据为原始产物核对 |
| P05 | 宣布通过前至少跑 3 条验证命令，附命令与输出 |
| P06 | 每个事实有锚点：文件路径与行号，或命令、工作目录、输出 |
| P07 | 假设标为假设，被推翻时撤回 |
| P08 | 需求逐字保存到 docs/spec/，不存链接或转述 |
| P09 | 行为测试与边界测试生成后哈希锁定，禁止改断言、加跳过、删测试 |
| P10 | 测试失败先保留失败回显，再改实现代码 |
| P11 | 通过标记需三条同时满足：独立验证通过、无未解决的已失败/未证实/受阻、自评 >= 7 |
| P12 | 通过标记附两个 SHA-1：diff 全文、独立验证报告全文；由独立验证者计算 |
| P13 | 未达条件写「未通过」，列未通过项与下一轮补齐计划 |
| P14 | 禁止改测试、改验收项、降低标准来拿通过标记 |
| P15 | 禁止同轮反复重做凑条件；连续两轮未达，停下报告卡点 |
