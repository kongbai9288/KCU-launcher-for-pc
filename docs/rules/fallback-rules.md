# 兜底规则

| 级别 | 定义 | 处理 |
| --- | --- | --- |
| 零级致命 | 应用无法继续 | 明确报错，提示修复，不崩溃 |
| 一级功能失效 | 单个功能不可用 | 禁用并提示 |
| 二级降级 | 可切换到替代路径 | 自动切换并提示已切换 |
| 三级忽略 | 不影响主流程 | 记日志 |

## 启动级

| 条件 | 动作 |
| --- | --- |
| 连续多次启动失败 | 进入安全模式，忽略自定义配置用内置默认 |
| 安全模式仍失败 | 导出诊断包 |

## 诊断包内容

| 项 | 内容 |
| --- | --- |
| 日志 | 运行日志全文 |
| 配置快照 | launch.json、config/launch.json、内置默认 |
| 运行时信息 | OS 版本、内存、Java 路径、WebView2 状态 |
| 已加载模块列表 | 模块名、版本、来源 |

## 诊断输出

`[KCU] <域> <动作> <目标> <结果> <详情>`

每条失败进日志且用户可见。禁用空捕获。
