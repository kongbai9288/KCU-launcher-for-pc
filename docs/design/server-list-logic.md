## 一条主链

```
用户加服务器
  → 立刻自动尝试连接（SLP 状态查询）
  → 把结果（能否连上 / 延迟 / 在线人数 / 版本 / MOTD / 图标）缓存下来
  → 缓存变成排序权重，驱动首页推荐卡与服务器列表
  → 双击 → 按「上次玩这个服的实例 + 上次用过的实例」在兼容范围里绑定 → 进服
```

游戏自己会在目录里写 `servers.dat`，启动器只读它来做自动分析；连接失败的排到下面，用户锁定的不受影响。

## 自动分析

| 项 | 口径 |
| --- | --- |
| 文件 | 各实例目录下 `servers.dat`（未压缩 NBT），有备份 `servers.dat_old` |
| 创建时机 | 默认不存在，游戏里加过服务器或进过任何服后才生成 |
| 字段 | `servers` List<Compound>：`name`、`ip`、`icon`（base64 PNG）、`acceptTextures`、`hidden`、`acceptedCodeOfConduct` |
| 两份列表 | 可见列表（游戏会主动同步信息）/ 隐藏列表（最多 16 个，不同步）；Quick Play 与直接连接进的服会落隐藏列表 |
| 其它来源 | 可不导隐藏列表，但快速进入过的地址默认一起导入；`options.txt` 的直连 IP、LAN 服务器不在此文件 |
| 读写 | 只读，不覆盖玩家在游戏里加的服；多实例隔离目录逐个扫 |
| 失败 | 文件不存在给空态；NBT 解析失败跳过该目录并可见提示，不影响其它实例 |

## 排序权重

| 序 | 规则 |
| --- | --- |
| 1 | 用户锁定的服务器，永远靠前；连不上也不下沉 |
| 2 | 连得上的：延迟低 > 最近玩过 > 在线人数 > 版本兼容度 |
| 3 | 连不上的排到列表最后 |
| 4 | 「不感兴趣」只降权，不隐藏 |

权重输入全部来自缓存的连接结果，不逐服务器单发全量详情；并发上限 3，慢源竞速取消；刷新只取增量，重新获取清缓存全量重测；失败保留上次结果并标灰，不空白。

## 显示（照游戏内）

| 元素 | 口径 |
| --- | --- |
| 图标 | 64×64 PNG，缺省用灰阶 pack.png 兜底；不符尺寸不渲染不缩放 |
| 名称 | 玩家自己填的名字，默认 `Minecraft Server` |
| MOTD | 两行；§ 颜色码或 text component 都接受；转义后显示，绝不执行脚本 |
| 人数 | `online / max`；字段缺失显示 `???` |
| 延迟 | 五格信号条：0–150 / 150–300 / 300–600 / 600–1000 / >1000 ms；连不上标「连不上」 |
| 版本 | `version.name`；缺了显示 unknown，不阻塞其余字段 |
| LAN | 局域网服务器自动列在底部 |
| 状态文案 | 不提供自定义颜色与文案，游戏显示什么就显示什么 |

SLP 只证明状态端点应答，不写成「能进服」；`enable-status=false` 的服务端看起来就是离线，给可见提示，不静默重试。

## 双击进服

| 序 | 动作 |
| --- | --- |
| 1 | 用户锁定过实例 → 按锁定的来 |
| 2 | 否则取「上次玩这个服用的实例」 |
| 3 | 否则取「上次全局用过的实例」 |
| 4 | 只在与服务器版本兼容的实例范围里挑 |
| 5 | 没有合适的 → 弹「换实例」，可取消；不静默失败 |
| 6 | 连接外部服务器首次提示会外传 IP / UUID，之后不再打断 |

弹窗显示：服务器名与地址、上次用该服的实例、上次全局实例、兼容范围、自动选定的实例；按钮「取消 / 换实例 / 进入」，× 与 ESC 也能关。

## 使用逻辑 12 项

| 编号 | 项 | 设计 |
| --- | --- | --- |
| L01 | 入口与首屏 | 一级导航「服务器」；首屏直接给按权重排好的列表 |
| L02 | 推荐与默认 | 锁定置顶，其余按连接缓存排序；首页推荐卡同源 |
| L03 | 缓存 | 连接结果有界缓存，含延迟、人数、版本、MOTD、图标 |
| L04 | 刷新 | 添加后自动连、打开列表自动同步一次、手动重新连接、重新获取清缓存全量重测、重新读取 servers.dat |
| L05 | 空态 | 没有服务器给「添加服务器」；`servers.dat` 不存在给说明 |
| L06 | 加载 / 取消 | 同步进度可取消，取消后 0 副作用 |
| L07 | 错误 / 降级 | 连不上沉底但保留条目；协议禁用给可见提示；解析失败跳过该目录 |
| L08 | 关闭 / 残留 | 进服弹窗、换实例、添加服务器弹窗都可关，流程结束 0 浮层 |
| L09 | 权限与确认 | 外传 IP / UUID 首次二次确认；servers.dat 只读 |
| L10 | 状态可见 | 上次同步时间、连得上 / 连不上台数、每台的人数与延迟 |
| L11 | 性能 | 并发 3、慢源取消、结果缓存、不逐服单发详情 |
| L12 | 可发现 | 一级导航、首页推荐卡、设置 → 服务器与连接、右键菜单 |
