| 项 | 值 |

## 规则

| 编号 | 内容 |
| --- | --- |
| P01 | 界面上不出现槽位 ID、锁定徽章、稳定设置 ID、`@modified`、`core.*` / `plugin.*`、构建状态、交接基线、新对话 6 步、候选未进构建、L4 以下 6 层、独立验证结论、哈希、四值、诊断号等工程叙事。 |
| P02 | 工程结论只落 `docs/`、`scripts/`、验证报告与轮次记录；界面只给结果与操作。 |
| P03 | 内部设计证据页可保留在 HTML 与 PNG 里，但必须标 `data-internal="1"`，不进产品导航、不进总览拼图。 |
| P04 | 功能仍照做，只是不喊出来：设置与关于固定在底部、插件只写扩展区、更新不替换核心，界面上不贴标签解释。 |
| P05 | 弹窗不显示内部 id；逻辑条用「上次更新 / 已就绪 / 待刷新 / 刷新 / 重新获取」这类用户语言，不写命中率术语。 |
| P06 | 关于页只留版本、平台、架构、开源许可入口、外观、第三方许可、开源致谢；不写「演示构建」「方案待定」「文档调研」。 |
| P07 | 第三方许可页保留（用户明确要求），但不写「进入 src/ 构建 0 项」这类状态；构建状态只登记在 `THIRD-PARTY-NOTICES.md`。 |
| P08 | 每轮渲染后复跑 P09 扫描，命中即修界面文案，不改工程文档。 |

## P09 扫描

扫描域为产品可见 HTML：去掉 script 块、style 块与四个 `data-internal="1"` 区块后再匹配 `slot:`、`core.*`、`plugin.*`、`@modified`、`setid`、`locked`、`未进构建`、`交接基线`、`新对话`、`独立验证`、`四值`、`SHA-1`、`命中率`、`方案待定`、`演示构建`。`docs/` 与 `scripts/` 不在域内。

```
python3 scripts/p09_scan.py
```

内部设计证据页标 `data-internal="1"` 后仍含工程词，按 P03 不算违规，总览拼图也不收录。021 复跑结果 `P09_HITS 0`。
