## 协议事实

| 编号 | 事实 | 四值 |
| --- | --- | --- |
| P01 | SLP 1.7+ 用常规协议：handshake 的 next state = 1 → Status Request（无字段）→ Status Response（JSON 字符串）→ Ping/Pong | 已证实 |
| P02 | JSON 含 `version.name` / `protocol`、`players.max` / `online` / `sample`、`description`（text component）、`favicon`（64×64 PNG base64）、`enforcesSecureChat` | 已证实 |
| P03 | `version.name` 应视为必需；`description` 是 text component，不是裸字符串；`players.sample` 不是完整玩家列表 | 已证实 |
| P04 | favicon 必须恰好 64×64 PNG，其余尺寸客户端静默不渲染 | 已证实 |
| P05 | SLP 可被服务端禁用；1.7 前后流程不兼容，现代客户端与服务端仍兼容新旧两种 | 已证实 |
| P06 | 第三方服务端可通过 ServerListPingEvent 改 MOTD、人数、图标，可取消事件让客户端看到离线 | 已证实（公开资料，第三方服务端行为） |
| P07 | 延迟是探测端到服务端的 TCP 往返，不等于玩家实际体感 | 已证实（公开资料） |
| P08 | Notchian 服务端 SLP 各字段的缺省行为细则 | 未证实 |

## 状态类型

| 类型 | 判定 | 色 | 用户可改 |
| --- | --- | --- | --- |
| 在线 | SLP 有响应且未超时 | 绿 | 可手动覆盖 |
| 维护中 | MOTD 含维护文案 / 手动设定 / 插件提供 | 金 | 可 |
| 离线 | 无响应或被取消事件 | 灰 | 可 |
| 满员 | `players.online >= players.max` | 金 | 可 |
| 私有 | 手动设定 | 灰 | 可 |
| 自定义 | 用户填文案与颜色 | 用户定 | 可 |

## 使用逻辑 12 项

| 编号 | 项 | 设计 |
| --- | --- | --- |
| L01 | 入口与首屏 | 设置 → 服务器状态；服务器页顶部显示状态条 |
| L02 | 推荐与默认 | 默认 SLP + 手动覆盖；手动值优先 |
| L03 | 缓存 | 状态结果缓存 60s，失败标灰，离线显示上次状态 |
| L04 | 刷新 | 手动重测、强制刷新清状态缓存、定时软刷新、事件驱动推视图；显示上次探测时间 |
| L05 | 空态 / 首次 | 无服务器给「添加服务器 / 一个参数直接进服」 |
| L06 | 加载 / 取消 | 探测进度可取消，取消后 0 副作用 |
| L07 | 错误 / 降级 | 超时标灰并保留缓存；协议被禁用给可见提示，不静默重试 |
| L08 | 关闭 / 残留 | 状态编辑面板可取消，流程结束 0 浮层 |
| L09 | 权限与确认 | 连接外部服务器提示将外传 IP / UUID，二次确认 |
| L10 | 状态可见 | 首页推荐卡、服务器列表、状态栏、右键菜单四处可显示；`[KCU]` 诊断行记录变更 |
| L11 | 性能 | 并发上限 3，慢源竞速取消，不逐服务器单发全量详情 |
| L12 | 可发现 | 设置搜索可命中「状态」，服务器页右键「设置状态」 |

## 自定义项

| 项 | 默认 | 范围 |
| --- | --- | --- |
| 探测间隔 | 60s | 全局 / 单服务器可覆盖 |
| 超时 | 3s | 全局 |
| 状态文案 | 空 | 单服务器 |
| 状态颜色 | 按类型 | 单服务器 |
| 显示位置 | 首页推荐卡 + 服务器列表 | 四个位置多选 |
| 变更历史 | 开 | `[KCU]` 单行诊断 |

## 失败与降级

| 场景 | 处置 |
| --- | --- |
| SLP 超时 | 保留 60s 内缓存，标灰，诊断行 DEGRADE |
| 协议被禁用 | 显示「服务端未开放状态查询」，可切仅手动 |
| JSON 缺 `version.name` | 版本显示 unknown，不阻塞其余字段 |
| `description` 为裸字符串 | 宽松解析，不崩，标记格式非标准 |
| favicon 尺寸不符 | 不渲染，不缩放，给提示 |
| ping 与玩家体感不一致 | 延迟数字旁标注「探测点往返」 |
