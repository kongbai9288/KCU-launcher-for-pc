# 推荐位目录与自定义设置

| 项 | 值 |
| --- | --- |
| 轮次 | 020 |
| 状态 | 已批准（设计层） |

## 推荐总控设置

| 设置 ID | 默认值 | 作用范围 | 说明 |
| --- | --- | --- | --- |
| core.rec.enabled | 开启 | 全局 | 总开关，关闭后所有推荐位只显示原始列表 |
| core.rec.weights_editable | 允许调数值与顺序 | 全局 | 权重数值可在设置里改 |
| core.rec.user_first | 永远排第一 | 全局 | 用户显式指定压过系统推荐 |
| core.rec.dismiss | 降权，不隐藏 | 全局 | 不感兴趣只降权，保留找回入口 |
| core.rec.sources | 本地 + 官方 + 插件 | 全局 | 三类来源可单独开关 |
| core.rec.refresh | 事件驱动 + 定时软刷新 | 全局 | 不弹窗、不抢焦点、不重置滚动 |
| core.rec.cache | 5min / 容量有界 | 全局 | 失效重取，离线显示上次快照 |
| core.rec.rank_table | 10 个推荐位统一 | 全局 | 排序口径单点维护 |

## 推荐来源可插拔

| 来源 | 槽位 | 规则 |
| --- | --- | --- |
| 本地 | core.rec.local | 最近使用、手动指定、已装内容 |
| 官方 | core.rec.official | 版本清单、公告、加载器元数据 |
| 插件 | plugin.rec.* | 只能追加候选，不改 core.rec.* 权重口径 |

## 服务器状态设置（用户点名项）

| 设置 ID | 默认值 | 说明 |
| --- | --- | --- |
| core.status.source | SLP 状态查询 + 手动覆盖 | 可切「仅手动」「插件提供」 |
| core.status.interval | 60s | 探测间隔 |
| core.status.timeout | 3s | 单次超时 |
| core.status.cache | 60s / 失败标灰 | 失败保留上次状态 |
| core.status.online | SLP 有响应 | 绿点 |
| core.status.maintenance | MOTD 可改 | 金点，服务端插件可改 MOTD |
| core.status.custom | 离线 / 满员 / 私有 | 灰点，可自定义文案 |
| core.status.label | 自定义文案与颜色 | 用户自由填写 |
| core.status.display | 首页推荐卡、服务器列表 | 状态栏、右键菜单可选 |
| core.status.history | `[KCU]` 诊断行 | 状态变更可追溯 |

SLP 一手字段与降级细则见 `docs/design/server-status.md`。
