## 核心锁定槽位（slot:core.locked.*）

| ID | 位置 | 顺序 | 变更权限 |
| --- | --- | --- | --- |
| core.locked.settings | 导航底部固定容器 | 第 1 位 | 不可改写 / 隐藏 / 重排 / 换 ID |
| core.locked.about | 导航底部固定容器 | 第 2 位 | 同上 |

容器带虚线描边、锁图标、`locked` 徽章；深浅主题、侧栏收起、插件安装、插件化更新四种状态都保持同一容器。

## 冲突处置

| 步 | 动作 | 可见反馈 |
| --- | --- | --- |
| 1 | 插件声明 core.* 槽位 | 注册表检出 ID 冲突 |
| 2 | 拒绝写入，保留原条目 | 「注册被拒绝 · core.locked.settings 已占用」 |
| 3 | 写 `[KCU]` 诊断行 | `plugins slot register DENY detail=core.locked.settings already_occupied` |
| 4 | 插件自身不崩溃 | 可改用 plugin.nav.* 重新注册 |
| 5 | 可复位 | 注册表回到干净态 |

## 插件清单校验

| 项 | 口径 | 来源 |
| --- | --- | --- |
| manifest | 只声明贡献，DATA，不执行代码 | J03 / R08 |
| 边界 | C ABI 或子进程隔离，Rust ABI 不跨边界 | R07 / R08 |
| 版本 | ABI_MAJOR 不匹配拒绝加载 | R07 |
| 校验 | 摘要 + 签名 + 路径遍历防护 | C01 |
| 预算 | 耗时上限，超时可终止 | C01 |
| 崩溃 | 高风险插件进程隔离，宿主不受影响 | C01 |

## 插件化更新

| 项 | 口径 |
| --- | --- |
| 形态 | 更新器本身是插件；更新包只替换插件包，核心二进制不动 |
| 通道 | 稳定 / 预览 / 插件化，用户可选 |
| 签名 | 不可禁用；公钥随配置，私钥不进仓库 |
| 版本 | 默认只接受更高版本；回滚需显式比较器 |
| 失败 | 保留旧插件，可见报错，可回滚，不半更新 |
| 端点 | 多端点只在非 2xx 时切换；畸形 2xx 不触发降级 |
| 许可 | 插件加载后在关于页动态追加许可信息 |
