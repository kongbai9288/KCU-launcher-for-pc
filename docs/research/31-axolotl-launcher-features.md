## 冲突与边界

1. **00-requirements 第 44 行「别人有的功能要有」被本轮指令收窄**：用户明确「列出来我选择性的让你去加入」，本轮零功能加入，等点名。按 00-18 第 5 条冲突裁决（用户当轮明确指令 > 文件规则）执行。
2. **AX23 与 11-18 冲突**：见候选表，不推定、不自动纳入。
3. **平台不一致**：官网只声明 Windows 10/11 x64 与 Windows ARM64（v1.11.0），macOS Intel / Apple Silicon，Linux x64。西西软件园写「WinAll, WinXP, Win7」，无代码或测试证据，标可信度低，不进候选。KCU 已定 32/64 位（11-8）、多处理器架构（11-27）、Win7 默认轻量模式（11-28），不能由 Axolotl 的平台声明推导。
4. **Win7 + 32 位 + EQ-01 未拍板**：AX01 / AX14 / AX15 / AX17 / AX20 都是重 UI 功能，渲染方案在 UI 框架口径落定前不能定。
5. **许可证**：Axolotl 桌面包 GPL-3.0-only，KCU 也是 GPLv3（11-26）。但 00-26 要求「每一个使用别人的源代码前面都要加上对应项目的许可证」，且「尽量使用开源代码」不等于可整段复制；点名后需单独立项核许可证与依赖闭包，本轮不引任何依赖。
