## 怎么运作

| 项 | 值 |
| --- | --- |
| 实现状态 | 未实现，src/ 为空 |
| 输入 | 各模块失败事件；连续启动失败计数；自定义配置；运行时信息 |
| 处理 | 失败分级 → 可见提示 → 自动切换或禁用 → 安全模式 → 诊断包导出 |
| 输出 | 提示、降级结果、诊断包、诊断行 |
| 分级 | 零级致命、一级功能失效、二级降级、三级忽略 |
| 安全模式 | 连续多次启动失败后忽略自定义配置，用内置默认 |
| 诊断包 | 日志全文、配置快照、运行时信息、已加载模块列表 |
| 错误路径 | 安全模式仍失败 → 导出诊断包；不崩溃、不静默跳过 |
| 空值 | 空模块列表、空配置按内置默认处理 |
| 超时 | 失败判定、诊断包写入、IPC 均设超时 |
| 编码 | 配置快照按 UTF-8；诊断行统一 UTF-8 |

| 入口 | 前置 | 动作 | 结果 |
| --- | --- | --- | --- |
| 单点失败 | 任意模式 | 自动分级 | 提示或降级可见 |
