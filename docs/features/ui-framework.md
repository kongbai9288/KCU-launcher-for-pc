## 怎么运作

| 项 | 值 |
| --- | --- |
| 实现状态 | 未实现，src/ 为空 |
| 输入 | 组件注册项；normal 模式设计稿；主题值；窗口尺寸 |
| 处理 | 组件注册表 → 窗口组装 → 主题切换 → 事件绑定 |
| 输出 | 桌面窗口、组件树、诊断行 |
| 组件范围 | 10 项导航、三栏布局、深浅双主题、表格、衣柜、工具箱、设备桥接面板、分步向导、右键菜单、日志抽屉 |
| 错误路径 | 设计稿加载失败、外部字体 CDN 失败、WebView2 缺失 → 二级降级或零级报错 |
| 空值 | 空组件列表、空主题值按内置默认处理 |
| 超时 | 资源加载、组件注册、IPC 均设超时 |
| 编码 | HTML / CSS / JS 按 UTF-8；外部字体失败时走本地字体栈 |
