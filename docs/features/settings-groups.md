## 怎么运作

设置页改为 9 个分组 chip：常规、下载与镜像、缓存与刷新、推荐与排序、服务器状态、AI 容器接口、插件与更新、隐私与诊断、实验性。每个设置项带稳定 `core.*` ID、默认值、作用范围，写后即时生效，失败保留旧值并可见报错；支持搜索、`@modified` 过滤、单项重置、恢复默认二次确认。AI 接口、缓存清理、插件更新、推荐权重、服务器状态等自定义项全部收在设置内，不再作为一级导航。

## 开放了什么

| 接口 | 类型 | 输入 | 输出 | 错误 |
| --- | --- | --- | --- | --- |
| `#view=settings&tab=<name>` | URL 路由 | 9 个分组名 | 对应分组面板 | 未知名回落 general |
| `[data-tab]` | chip | 分组名 | 面板切换 + 诊断行 | 无 |
| `tabModified` / `tabReset` | 按钮 | 无 | @modified / 恢复默认确认 | 取消 0 副作用 |
| `setCacheExpired` / `setCacheAll` / `setAiTest` | 按钮 | 无 | 清理、测试反馈 | 失败可见 |
