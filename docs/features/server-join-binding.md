## 怎么运作

双击服务器直接进入。实例绑定顺序：用户锁定过实例 → 按锁定的来；否则取「上次玩这个服用的实例」；否则取「上次全局用过的实例」；只在与服务器版本兼容的实例范围里挑。没有合适实例给「换实例」，可取消，不静默失败。弹窗显示服务器名与地址、上次用该服的实例、上次全局实例、兼容范围、自动选定结果；按钮取消 / 换实例 / 进入，× 与 ESC 也能关，流程结束 0 浮层。连接外部服务器首次提示会外传 IP / UUID，之后不再打断。
