## 怎么运作

| 项 | 值 |
| --- | --- |
| 实现状态 | 未实现，src/ 为空；具体保护方案未批准 |
| 输入 | 用户在其他模式留存的正版凭据；当前 Windows 登录用户上下文 |
| 处理 | 凭据写入前加密 → 落盘到用户目录 → 读取时解密 → 校验失败返回统一错误 |
| 输出 | 加密 blob、解密结果、诊断行 |
| 候选 | `CryptProtectData` / `CryptUnprotectData`；`CredWriteW` / `CredReadW`，一手原文见 docs/research/12-compliance.md |
| 排除 | `CRYPTPROTECT_LOCAL_MACHINE`；凭据不进入日志、诊断包、配置快照 |
| 错误路径 | 加密失败、解密失败、登录用户变更、SID 被禁用、blob 损坏 → 零级或一级失败可见，不返回空值 |
| 空值 | 空凭据、空 blob、空目标名按统一错误返回 |
| 超时 | 凭据读写、IPC 均设超时 |
| 编码 | blob 为二进制，显式编码声明；配置与日志按 UTF-8 |
| 未证实项 | `CRED_PERSIST_*` 取值、令牌刷新周期、Azure Client ID |

## 用户使用逻辑

| 入口 | 前置 | 动作 | 结果 |
| --- | --- | --- | --- |
| 其他模式完成正版登录 | 凭据有效 | 写入受保护存储 | 后续会话可复用 |
| 无头模式启动 | 此前留存凭据 | 读取并校验 | 成功则允许正版，失败则禁用并提示 |
| 登录用户变更 | 凭据存在 | 解密校验 | 失败可见，不静默降级 |
| 凭据删除 | 用户主动 | 删除 blob | 会话不再复用 |
