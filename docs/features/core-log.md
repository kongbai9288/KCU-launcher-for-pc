## 怎么运作

`LogBuffer::new(per_file)` 拒绝 0；`push` 追加行，达到 per_file 就把当前批移入 shards；`flush` 返回全部满批 + 末尾不足一批，并清空。压缩成 zip 由上层做，本层只负责「每 N 条一个分片」的边界。

## 开放了什么

| 接口 | 类型 | 输入 | 输出 | 错误 |
| --- | --- | --- | --- | --- |
| `new` / `push` / `flush` | 函数 | usize / Into<String> / 无 | Self / () / Vec<Vec<String>> | per_file=0 时 panic |
| `shard_count` / `pending` | 函数 | 无 | usize | 无 |
