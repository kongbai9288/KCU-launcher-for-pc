## 怎么运作

| 项 | 值 |
| --- | --- |
| 实现状态 | 未实现，src/ 为空 |
| 输入 | 各模块日志行；游戏进程 stdout / stderr；诊断行 |
| 处理 | 统一信封事件 → 格式化 → 写文件 → 视图订阅 |
| 输出 | 日志文件、日志视图、诊断行 |
| 诊断格式 | `[KCU] <域> <动作> <目标> <结果> <详情>` |
| 错误路径 | 写入失败、磁盘满、句柄占用 → 一级失败可见，不丢行到空捕获 |
| 空值 | 空日志行、空字段按占位写入，不返回空值 |
| 超时 | 文件写入、IPC 订阅均设超时 |
| 编码 | 日志输出统一 UTF-8；控制台代码页差异不进入判断逻辑 |

## 开放了什么

| 接口 | 类型 | 输入 | 输出 | 错误 |
| --- | --- | --- | --- | --- |

| 诊断行 | 函数 | 域、动作、目标、结果、详情 | 单行文本 | 统一错误 |
| 订阅 | 事件 | 订阅标识 | 日志事件流 | 统一错误 |
| 导出 | 函数 | 时间范围 | 日志文件 | 统一错误 |
