## 怎么运作

| 项 | 值 |
| --- | --- |
| 实现状态 | 未实现，src/ 为空 |
| 输入 | 用户选择的登录方式；下载源选择；日志开关；加载器选择 |
| 处理 | 简单 webview 承载网页登录；外置浏览器 → 内置浏览器 → 连接码三级回退；小文件拉起启动器后退出 |
| 输出 | 游戏进程、日志文件；管理文件动作交给系统文件管理面板 |
| 视图范围 | 三种登录入口、基础日志；不含 normal 模式 UI 的任何组件与资产 |
| 错误路径 | WebView2 缺失、外置浏览器失败、内置浏览器失败、连接码超时 → 逐级降级并写诊断行；全部失败时零级报错 |
| 空值 | 无网络、空账号、空下载源、空列表按内置默认处理 |
| 超时 | 网络、进程启动、IPC、连接码轮询均设超时 |
| 编码 | json 与日志按 UTF-8；路径按 OsStr |
| 排除项 | normal.ui 框架、assets/ui/normal-mode-v3.html、揉纸纹理、浅色/深色双主题、三栏拖拽、table.grid、衣柜、工具箱、设备桥接面板、分步向导、右键菜单、日志抽屉，见 docs/decisions/007-normal-ui.md D03-D05 |

## 用户使用逻辑

| 入口 | 前置 | 动作 | 结果 |
| --- | --- | --- | --- |
| 首次启动 | 内存 ≤ 2GB | 自动进入 | 极简登录视图 |
| 网页登录 | WebView2 可用 | 外置浏览器登录 | 登录完成 |
| 一级回退 | 外置浏览器不可用 | 打开内置浏览器 | 登录完成；已切换提示 |
| 二级回退 | 内置浏览器不可用 | 显示连接码 | 用户用手机完成登录 |
| 管理文件 | 用户点击 | 打开系统文件管理面板 | 无内嵌管理器 |
| 游戏运行期 | 游戏进程已启动 | 轻量启动器退出 | 后台无常驻进程 |
