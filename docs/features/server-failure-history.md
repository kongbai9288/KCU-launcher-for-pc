## 怎么运作

把「瞬时连不上」与「有没有成功案例」分开。`ever=true` 的服务器继续参与后续探测，本轮失败沉底到 900 档；`ever=false && tried=true` 的不主动探测，用缓存权重排在 300 档中段，不沉底、不置顶、不隐藏；`probeSkip=out` 的范围外项用缓存权重排 200 档；锁定项 0 档，连不上、超范围、无成功记录都不改变位置。缓存权重取最近使用时间与上次延迟，不依赖本轮网络。

| 项 | 值 |
| --- | --- |
| 实现状态 | 演示层；`src/` 本轮无变化 |
| 输入 | `ui.demo / servers.rank` |
| 输出 | 增量渲染的服务器列表、预算四格与进度条、`[KCU]` 诊断行 |
| 错误路径 | 单台超时跳过、取消后 0 新请求、失败不毁整批 |
| 空值 | 没有服务器给添加入口；档位 0 给「本次不连」 |
| 超时 | 单台 deadline，慢源跳过 |
| 排除项 | 不随服务器总数线性扩连接数；不无限堆积队列 |
