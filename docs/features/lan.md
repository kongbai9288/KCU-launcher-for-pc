## 怎么运作

| 项 | 值 |
| --- | --- |
| 实现状态 | 未实现，src/ 为空 |
| 输入 | 同一局域网下的手机端连接请求；本地文件与目录路径 |
| 处理 | 设备发现 → 配对 → 协议握手 → 文件互传 |
| 输出 | 传输结果、设备列表、诊断行 |
| 协议 | 手机端尚未支持，协议由本项目设计，见 docs/research/07-lan.md |
| 错误路径 | 设备不可达、配对失败、传输中断、校验失败 → 一级失败可见或二级降级 |
| 空值 | 空设备列表、空文件集合、空元数据按统一错误返回 |
| 超时 | 发现、握手、每个传输块均设超时 |
| 编码 | 元数据按 UTF-8；文件名按 UTF-8；路径按 OsStr |
