## 怎么运作

用户添加完服务器立即自动尝试连接；打开服务器列表自动同步一次；结果（能否连上、延迟、在线人数、版本、MOTD、图标）缓存为排序权重，驱动首页推荐卡与服务器列表。排序规则：锁定置顶且连不上也不动 → 连得上按延迟、最近使用、在线人数、版本兼容 → 连不上沉底；不感兴趣只降权不隐藏。刷新取增量，重新获取清缓存全量重测，失败保留上次结果并标灰。

## 开放了什么

| 接口 | 类型 | 输入 | 输出 | 错误 |
| --- | --- | --- | --- | --- |
| `data-v="servers"` | 路由 | 无 | 按权重排好的列表 | 无 |
| `srvAdd` / `srvRecRefresh` / `srvScan` | 按钮 | 无 | 自动连接、重新连接、重读列表 | 失败沉底 |
| `[data-lock]` | 星标 | 服务器 ID | 锁定切换与重排 | 无 |
| `srvLb .lb-soft/.lb-hard` | 逻辑条 | 无 | 增量 / 全量刷新 | 失败回退缓存 |

## 用户使用逻辑

| 入口 | 动作 | 结果 |
| --- | --- | --- |
| 添加服务器 | 填完地址 | 立刻自动连一次并排进列表 |

| 星标 | 点一下 | 锁定 / 取消，立即重排 |
| 首页推荐卡 | 看两张 | 与服务器列表同一套权重 |
