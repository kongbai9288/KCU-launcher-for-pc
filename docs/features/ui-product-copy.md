## 怎么运作

界面上不再出现槽位 ID、锁定徽章、稳定设置 ID、`@modified`、构建状态、交接基线、独立验证结论、诊断号等工程叙事；工程结论只落 docs/ 与验证报告。四个内部设计证据区块标 `data-internal="1"`，不进产品导航、不进总览拼图。设置与关于仍固定在底部、插件只写扩展区、更新不替换核心，功能照做但不贴标签解释。逻辑条改「上次更新 / 已就绪 / 待刷新 / 刷新 / 重新获取」，弹窗隐藏内部 id，关于页只留版本、外观、第三方许可、开源致谢。
