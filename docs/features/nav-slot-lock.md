## 怎么运作

一级导航收敛为 9 项日常操作；AI 接口、数据与缓存、刷新机制、状态与降级、无头模式、第三方许可移出一级导航，分别落进设置、关于或设计证据页。`core.locked.settings` 与 `core.locked.about` 固定在导航底部同一容器，带虚线描边、锁图标与 `locked` 徽章；插件区 `slot:plugin.*` 是独立容器，只能追加条目。槽位注册表页可模拟插件占用核心槽位：拒绝写入、保留原条目、显示可见拒绝提示、写 `[KCU]` 诊断行，插件自身不崩溃。工具条操作按视图收敛，设置 / 关于 / 许可 / 槽位等页面不显示列表网格、刷新、新建实例按钮。

## 开放了什么

| 接口 | 类型 | 输入 | 输出 | 错误 |
| --- | --- | --- | --- | --- |
| `data-v="settings"` / `data-v="about"` | 锁定路由 | 无 | 固定槽位页面 | 插件不可改写 |
| `data-v="slots"` | 路由 | 无 | 槽位注册表 | 无 |
| `slotConflict` / `slotReset` / `slotDenyClose` | 按钮 | 无 | 拒绝提示 / 复位 | 拒绝注册 |
| `.tb-actions` 显隐 | 视图状态 | 视图名 | 操作按钮显示或隐藏 | 无 |
